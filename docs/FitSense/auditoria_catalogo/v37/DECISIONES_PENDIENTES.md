# Casos que necesitan una decisión funcional o humana

Estos casos **no entran en V37**: son veredictos `PENDIENTE_CRITERIO` o `PROBABLE` de la matriz completa.
- Cada grupo necesita una regla del responsable del proyecto, o una segunda revisión humana.
- Ninguno se ha resuelto automáticamente.

Hay además 41 confirmados que no se pueden expresar con el esquema actual: implementos no modelados o textos por redactar. Están en `no_incluidas_v37.tsv`.
